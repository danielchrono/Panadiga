# Utilitários de Baixo Nível (`tools/`)

Este diretório contém utilitários de suporte e análise hexadecimal para trabalho de bancada.

* **HxD Hex Editor Portable:** Utilizado para inspeção visual rápida de setores e dumps de firmware.
  * O launcher portátil [`Abrir_HxD.bat`](file:///c:/Users/danie/Documents/Panasonic%20Firmware%20HDD%20bin/tools/Abrir_HxD.bat) abre o editor HxD configurado para a arquitetura do sistema operacional (32-bit ou 64-bit).
  * O HxD pode ser baixado em sua versão oficial em: https://mh-nexus.de/en/hxd/
